# CPK 산출기 다운로드

검사 CSV의 공정능력(Cp/Cpk · Pp/Ppk)을 분석하고 히스토그램과 PDF 보고서로 확인하는 Windows 프로그램입니다.

**[최신 버전 다운로드](https://github.com/kmisystem-csharp/cpk-viewer-releases/releases/latest)**

1. 최신 릴리즈에서 `CpkViewer-v버전-win-x64.exe` 파일을 내려받습니다.
2. [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0)을 설치합니다.
3. 내려받은 실행 파일을 실행합니다. 별도 프로그램 설치 과정은 없습니다.

이 저장소는 실행 파일 배포용입니다. 프로그램 소스는 비공개로 관리합니다.
